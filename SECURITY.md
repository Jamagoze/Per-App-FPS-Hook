# Security Policy

## Supported Versions

The following table lists the active support status for versions of the Per-App-FPS-Hook repository (`Jamagoze/Per-App-FPS-Hook`). Because this project interacts with low-level system components, runtime configurations, and overlay hooks, only the latest commit on the main branch receives active security updates and patch support.

| Version | Supported |
| :--- | :--- |
| Latest (`main`) | :white_check_mark: Yes |
| Older / Archived Commits | :x: No |

---

## Reporting a Vulnerability

If you discover a security vulnerability, privilege escalation risk, or stability flaw within this project, please report it responsibly rather than opening a public issue.

* **Reporting Channel:** Send details directly via private communication or open a security advisory draft if available on the GitHub repository interface.
* **Information to Include:**
  * A clear description of the vulnerability and its potential impact.
  * Steps, scripts, or environment configurations required to reproduce the issue (e.g., Android version, ROM, root implementation, and targeted application packages).
  * Any proposed remediation or patch concepts if you have developed a fix.

Maintainers will review the submission and coordinate a patch strategy before public disclosure.
